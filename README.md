# Ziqi Liu · Applied AI Portfolio

Personal portfolio featuring AI Agent operations, conversational AI evaluation, and Aussie EcoLens.

## Publish

Enable GitHub Pages from the `main` branch and `/ (root)`. The site uses plain HTML, CSS and JavaScript; no build step is needed.

## Assets

Fonts, the Liquid scene, its texture and pinned Unicorn Studio runtime are served locally. The Liquid effect requires WebGL. Source: [Framer University Hover Chroma Backgrounds](https://framer.university/resources/hover-chroma-backgrounds-in-framer). Font license files are included in `assets/`.
